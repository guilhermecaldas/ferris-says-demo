# Ferris Says - Demo

A simple Rust demo project that uses the `ferris-says` crate to display messages with Ferris the crab.

## Features

- Displays custom messages with ASCII art formatting
- Uses the `ferris-says` crate for console output styling

## Building

```bash
cargo build
```

## Running

```bash
cargo run
```

This will output a greeting message with Ferris the crab.

```plain
 ______________________
< Oi gurizada medonha! >
 ----------------------
        \
         \
            _~^~^~_
        \) /  o o  \ (/
          '_   -   _'
          / '-----' \
```

## Dependencies

- `ferris-says` - ASCII art message display library
